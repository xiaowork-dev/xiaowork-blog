# XiaoWork Blog v1.0.0-rc.6（预发布）

> **预发布版本**，用于生产环境上线验收，取代 `v1.0.0-rc.5`。验收通过后，将在**同一提交**上发布正式版 `v1.0.0`。

## 亮点：按效果图改版，新增收藏、记住我、相关文章

- **新样式**（按项目负责人提供的效果图）：
  - 浅灰页面配白卡片，统一科技蓝；深色模式为深海军蓝；
  - 文章卡片更紧凑：左侧封面，标题与两行摘要；分类为蓝色胶囊，标签为灰色；底部为日期 · 阅读量和收藏按钮；
  - 资料卡下方增加站点导航（手机端为横向标签）；
  - 文章页改为“正文 + 右侧目录 / 相关文章”。
- **收藏**：
  - 登录后可在文章卡片或文章页收藏文章，在“个人中心 → 我的收藏”中查看；
  - 文章撤回后会暂时从收藏中隐藏，重新公开后恢复。
- **记住我**：登录页可选。勾选时保持登录 14 天；不勾选时关闭浏览器即退出。
- **相关文章**：文章页显示最多 3 篇相关文章。
- **修复**：部分手机设置了系统字体后，整站显示为楷体/宋体风格；现在优先使用无衬线中文字体。

## 升级说明

- 数据库迁移：新增 `00008_bookmarks.sql`（只新增一张收藏表）。
  - 更新时自动执行，结构版本 7 → 8；
  - 回滚到旧版本时旧代码不使用这张表，可以直接回滚。
- 配置变化：无，`deploy/.env` 不需要修改。
- 需要人工处理的步骤：无。
- 已安装 rc.5 的服务器：

  ```bash
  sudo deploy/manage.sh update v1.0.0-rc.6 --pre
  ```

  回滚：

  ```bash
  sudo deploy/manage.sh rollback
  ```

## 已知限制

- 收藏状态在浏览器中加载：刷新页面时，书签图标会短暂显示为未收藏。
- 单机部署，请配置异地备份；回滚不回退数据库结构。
