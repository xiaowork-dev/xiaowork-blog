# XiaoWork Blog v1.0.0-rc.7（预发布）

> **预发布版本**，用于生产环境上线验收，取代 `v1.0.0-rc.6`。验收通过后，将在**同一提交**上发布正式版 `v1.0.0`。

## 亮点：宽屏自适应

- **页面宽度随窗口变化**：
  - 1500 px 以下的窗口（笔记本）：与以前相同，最宽 1200 px；
  - 更宽的窗口：约为窗口宽度的 80%，最宽 1680 px（例如 27 寸 2560 屏）。
- 窗口 1600 px 以上时：
  - 左侧资料栏加宽到 288 px，文章卡片封面加大到 260 px；
  - 文章页正文字号 18 px；
  - 文章页最宽 1440 px，以保持每行字数适合阅读。

## 修复

- 文章没有目录、也没有相关文章时，右侧不再留出一块空侧栏；正文改为居中显示（最宽 1100 px）。

## 升级说明

- 数据库迁移：无，结构版本仍为 8。
- 配置变化：无，`deploy/.env` 不需要修改。
- 需要人工处理的步骤：无。
- 已安装 rc.6 的服务器：

  ```bash
  sudo deploy/manage.sh update v1.0.0-rc.7 --pre
  ```

  回滚：

  ```bash
  sudo deploy/manage.sh rollback
  ```

## 已知问题

- 收藏状态在浏览器中加载：刷新页面时，书签图标会短暂显示为未收藏。
- 单机部署，请配置异地备份；回滚不回退数据库结构。
