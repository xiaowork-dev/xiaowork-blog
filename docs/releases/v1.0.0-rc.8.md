# XiaoWork Blog v1.0.0-rc.8（预发布）

> **预发布版本**，用于生产环境上线验收，取代 `v1.0.0-rc.7`。验收通过后，将在**同一提交**上发布正式版 `v1.0.0`。

## 亮点：页面铺满窗口

- **不再限制页面最大宽度**：顶栏和内容随窗口铺满，左右只留 16–48 px 边距；大屏或浏览器缩小时两侧不再出现大片留白。
- **文章列表自动分列**：每列至少约 620 px，放得下几列就排几列。
  - 笔记本：1 列；
  - 2560 宽屏幕：3 列；
  - 文章少时，卡片会拉宽占满整行。
- **文章页**：卡片铺满整行；正文在卡片中居中，宽度约为卡片的三分之二（至少 900 px），随窗口一起变宽，避免一行字过长。

## 升级说明

- 数据库迁移：无，结构版本仍为 8。
- 配置变化：无，`deploy/.env` 不需要修改。
- 需要人工处理的步骤：无。
- 已安装 rc.7 的服务器：

  ```bash
  sudo deploy/manage.sh update v1.0.0-rc.8 --pre
  ```

  回滚：

  ```bash
  sudo deploy/manage.sh rollback
  ```

## 已知问题

- 收藏状态在浏览器中加载：刷新页面时，书签图标会短暂显示为未收藏。
- 单机部署，请配置异地备份；回滚不回退数据库结构。
