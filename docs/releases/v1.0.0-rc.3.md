## 主要变化：支持 1Panel / 主机网络反向代理

新增 `PROXY_MODE`，安装时选择：

| 方式 | 适用 | 博客端口 |
|---|---|---|
| `docker-network`（默认，与 rc.2 相同） | Nginx Proxy Manager 等容器反代，共享自定义 Docker 网络 | 不发布任何主机端口 |
| `host-loopback`（新增） | 1Panel 的 OpenResty 等**使用主机网络**的反代，或主机上的 nginx | 只发布到 `127.0.0.1:13000`（web）与 `127.0.0.1:18081`（api），端口可改 |

- 两种方式下，Nuxt、Go API、PostgreSQL 都是独立容器，不使用主机网络；数据库不发布端口。
- host-loopback 不需要 `PROXY_NETWORK`，也不需要 NPM。
- 可信代理只包含博客自己的 app 网段：
  - 伪造的 `X-Forwarded-For` 会被忽略；
  - 真实客户端 IP 取自 OpenResty 追加的地址。
- 引导式安装：
  - 检测到主机网络上的 OpenResty / nginx 时，自动建议 host-loopback；
  - 检查端口占用与网段冲突；
  - **不会停止任何其他服务**。
- `precheck` 新增第 7b 节：
  - 主机网络上的反代容器；
  - 80/443 由谁监听；
  - 两个端口是否空闲；
  - Compose 版本是否满足要求。
- 新文档：
  - `docs/deploy/1Panel-OpenResty部署指南.md`（网络结构、1Panel 配置步骤、生产配置示例、检查与排障）；
  - 参考配置 `deploy/nginx/openresty-host-loopback.conf`。

## 其他修复

- 修复：服务正常时再次运行 `manage.sh install`，现在会按 `deploy/.env` 的改动重建有变化的容器（例如切换反代方式、修改端口）；没有改动时不重建任何容器。以前会直接退出，改动不生效。

## 升级说明

- **已安装 rc.1 / rc.2（NPM）**：
  - 运行 `sudo deploy/manage.sh update v1.0.0-rc.3 --pre`；
  - `deploy/.env` **不需要修改**（没有 `PROXY_MODE` 时按 docker-network 处理）；
  - 演练中已验证：由 rc.2 的 `update.sh` 升级后，web/api 仍在 NPM 网络中，数据一致；回滚到 rc.2 也正常。
- **新的 1Panel 服务器**：按 1Panel 部署指南安装：
  ```bash
  sudo deploy/manage.sh install v1.0.0-rc.3 --pre
  ```
  安装时选择 host-loopback。
- **已安装的 NPM 服务器改用 1Panel**：
  1. 在 `.env` 中设置 `PROXY_MODE=host-loopback`；
  2. 清空 `TRUSTED_PROXY_CIDRS=`；
  3. 运行 `sudo deploy/manage.sh install`。

  演练中已验证两个方向的切换，数据保持不变。
- 数据库迁移：无新增，数据库结构版本仍为 7。
- 新配置项（都可选）：
  - `PROXY_MODE`；
  - `WEB_HOST_PORT`、`API_HOST_PORT`（只用于 host-loopback）。
- host-loopback 需要 **Docker Compose 2.24.4 或以上**；docker-network 仍为 2.20+。

## 安装

```bash
sudo git clone https://github.com/xiaowork-dev/xiaowork-blog.git /opt/xiaowork-blog
cd /opt/xiaowork-blog
sudo deploy/manage.sh precheck                         # 可选：只读环境预检
sudo deploy/manage.sh install v1.0.0-rc.3 --pre
```

完整步骤：

- NPM：`docs/deploy/部署与运维手册.md`；
- 1Panel：`docs/deploy/1Panel-OpenResty部署指南.md`。

## 已知限制

- host-loopback 下，本机任何使用主机网络的进程都能访问两个回环端口，并自带 `X-Forwarded-For`。这只影响按 IP 计算的限流，不能绕过认证、CSRF 与权限检查。
- host-loopback 的安装无法回滚到 rc.2 或更早版本：旧版本不支持该模式。
- 1Panel 界面本身未在演练中操作。请以生成的 OpenResty 配置和指南第 6 节的检查结果为准。
- 单机部署，图片保存在本地目录；请配置异地备份。
- 回滚只切换应用版本，不回退数据库结构。
- 剩余风险见 `docs/deploy/性能基线与剩余风险.md`。
