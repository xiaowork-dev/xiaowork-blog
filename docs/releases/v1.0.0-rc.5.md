# XiaoWork Blog v1.0.0-rc.5（预发布）

> **预发布版本**，用于生产环境上线验收，取代 `v1.0.0-rc.4`。验收通过后，将在**同一提交**上发布正式版 `v1.0.0`。

## 亮点：新配色「墨绿青蓝」

- **只换颜色**：布局、卡片结构、功能都与 rc.4 相同。
- **深色模式层次更清楚**：
  - 墨绿底（`#0C1312`）与卡片（`#131D1B`）、顶栏明暗分明；
  - 蓝色 Logo 和文章封面在绿调背景上更突出；
  - 资料卡顶部色带不再发浑。
- **青绿主色 + 琥珀点缀**：
  - 链接、按钮、导航激活态（新增下划线）、标签使用青绿；
  - 分类圆点与行内代码使用琥珀；
  - 其余标签使用低饱和天蓝与靛紫。
- **浅色模式**：带一点绿调的浅灰背景（`#F4F7F6`）配深青主色（`#0F766E`），清爽、护眼。
- **可读性**：所有文字对比度 ≥ 4.5:1（WCAG AA）。

## 文档

- 新增“收不到验证邮件”的排查：很多 VPS 服务商会封锁出站 25/465/587。
  - 现象：日志中出现 `smtp dial: … i/o timeout`；
  - 解决：请服务商开放端口，或改用邮件服务商的备用端口（如 `SMTP_PORT=2465`、`SMTP_TLS=tls`）；
  - 详见运维手册 §13。

## 升级说明

- 数据库迁移：无，结构版本仍为 7。
- 配置变化：无，`deploy/.env` 不需要修改。NPM 与 1Panel host-loopback 两种方式都兼容。
- 需要人工处理的步骤：无。
  - 更新时会重新构建 web 镜像。
  - 服务器访问 npm 源不稳定时，可在 `deploy/.env` 中设置 `NPM_REGISTRY=https://registry.npmmirror.com/`。
  - 构建失败时更新会自动中止，网站继续运行当前版本。
- 已安装 rc.4 的服务器：

  ```bash
  sudo deploy/manage.sh update v1.0.0-rc.5 --pre
  ```

  回滚：

  ```bash
  sudo deploy/manage.sh rollback
  ```

## 已知限制

- 与 rc.4 相同：
  - 已发布文章的旧自动摘要需要“编辑 → 发布更新”后才会按新规则重新生成；
  - 单机部署，请配置异地备份；
  - 回滚只切换应用版本，不回退数据库结构（本版本没有迁移）。
