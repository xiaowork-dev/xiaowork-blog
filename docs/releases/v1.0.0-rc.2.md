# XiaoWork Blog v1.0.0-rc.2（预发布）

> **预发布版本**，用于生产环境上线验收，**取代 `v1.0.0-rc.1`**。验收通过后，将在**同一提交**上发布正式版 `v1.0.0`，已安装 rc.2 的服务器无需重新部署。不建议在验收之外的生产网站上使用预发布版本。

## 升级说明

- 尚未安装任何版本：直接安装 rc.2（见下方）。
- 已安装 rc.1：`sudo deploy/manage.sh update v1.0.0-rc.2 --pre`。
- 数据库迁移：无新增，数据库结构版本仍为 7。
- 配置：没有变化。
- 需要人工完成的步骤：与 rc.1 相同（首次安装后在 NPM 中新增代理主机、创建管理员、配置备份）。

## 安装

```bash
sudo git clone https://github.com/xiaowork-dev/xiaowork-blog.git /opt/xiaowork-blog
cd /opt/xiaowork-blog
sudo deploy/manage.sh precheck                         # 可选：只读环境预检
sudo deploy/manage.sh install v1.0.0-rc.2 --pre
```

需要：64 位 Linux、Docker Engine 24+、Compose 2.20+，以及已运行的 Nginx Proxy Manager（位于自定义 Docker 网络中）。完整步骤见 `docs/deploy/部署与运维手册.md`。

## 相比 rc.1 的变化

- **修复**：`manage.sh` / `update.sh` 拉取发布标签时的误报。
  - 本地标签与远端标签指向同一提交、只是标签对象不同时（例如 CI 浅克隆创建的轻量标签），以前会被误判为“远端标签被移动”并停止。现在会改用远端标签并继续。
  - 只有指向不同提交时才判定为篡改并拒绝，同时显示本地与远端的提交。
- **CI**：部署测试作业拉取完整历史与标签，并新增回归测试（同一提交的轻量标签被接受，被移动的标签被拒绝）。
- 应用功能、数据库与配置与 rc.1 相同。

## 内容

V1.0 的全部功能：博客前台、Markdown 写作、用户与评论、管理后台、媒体与隐私保护、安全加固，以及统一管理入口 `deploy/manage.sh`（安装、检查与确认更新、备份、恢复、回滚、只读预检）。详见 `docs/releases/v1.0.0.md` 与 `CHANGELOG.md`。

## 已知限制

- 依赖已有的 Nginx Proxy Manager；暂不提供独立反向代理安装模式。
- 单机部署，图片保存在本地目录；请配置异地备份。
- 回滚只切换应用版本，不回退数据库结构。
- 剩余风险见 `docs/deploy/性能基线与剩余风险.md`。
