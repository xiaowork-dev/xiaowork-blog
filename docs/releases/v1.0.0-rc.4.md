# XiaoWork Blog v1.0.0-rc.4（预发布）

> **预发布版本**，用于生产环境上线验收，取代 `v1.0.0-rc.3`。验收通过后，将在**同一提交**上发布正式版 `v1.0.0`。
>
> 本文件是发布草稿：标签与 GitHub Release 需要项目负责人确认后才创建。

## 亮点：保留简洁布局的轻量视觉升级

- **布局不变**：顶部导航、左侧个人资料栏、右侧文章列表都保持原样，没有增加任何组件。
- **配色更有层次**：
  - 浅色与深色各一套 Design Tokens；
  - 科技蓝为主色，低饱和的青、橙、紫用于分类与标签；
  - 渐变只用于细线；
  - 所有文字对比度 ≥ 4.5:1（WCAG AA）。
- **文章卡片**：
  - 封面统一 16:9 且不会变形；
  - 首屏优先加载，加载失败时显示柔和的占位；
  - 无封面文章保持纯文字卡；
  - 标题、摘要、分类、日期、标签、阅读量层次分明。
- **资料卡**：浅色顶带、头像描边、外链按钮的悬停与键盘聚焦状态。
- **文章详情**：
  - 标题区重新排版，封面作为头图（正文里已有同一张图时不重复显示）；
  - 代码块、引用、表格、链接、图片的样式更适合中文长文阅读。
- **编辑器**：
  - 工具栏按功能分组，模式切换改为分段按钮；
  - 深色模式下的 Markdown 语法高亮更易读；
  - 预览区宽度与正文一致。
  - 自动保存、手动发布、版本冲突检测都没有改动。

## 修复

- 没有手动摘要的文章，首页、RSS 和搜索引擎描述中不再出现代码命令、表格内容、图片说明和长链接。
  - 手动摘要依然优先。
  - 站内搜索仍然能搜到代码内容。

## 升级说明

- 数据库迁移：无，结构版本仍为 7。
- 配置变化：无，`deploy/.env` 不需要修改。NPM 与 1Panel host-loopback 两种反代方式都兼容。
- 需要人工处理的步骤：
  - 已发布文章的自动摘要**不会被自动改写**。
    - 如果某篇文章的首页摘要里有代码或链接，在后台打开它，做任意修改后“发布更新”，摘要就会按新规则重新生成。
    - 也可以直接填写手动摘要。
  - 更新时会重新构建 web 镜像。
    - 如果服务器访问 npm 源不稳定，可在 `deploy/.env` 中设置 `NPM_REGISTRY=https://registry.npmmirror.com/`。
    - 构建失败时更新会自动中止，网站继续运行当前版本。
- 已安装 rc.3 的服务器：

  ```bash
  sudo deploy/manage.sh update v1.0.0-rc.4 --pre
  ```

  回滚：

  ```bash
  sudo deploy/manage.sh rollback
  ```

## 已知限制

- 单机部署，图片保存在本地目录；请配置异地备份。
- 回滚只切换应用版本，不回退数据库结构（本版本没有迁移）。
- 剩余风险见 `docs/deploy/性能基线与剩余风险.md` 与 `docs/handoffs/P8-B8_UI配色与封面优化交付.md`。
