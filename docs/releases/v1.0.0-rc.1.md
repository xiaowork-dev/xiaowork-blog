# XiaoWork Blog v1.0.0-rc.1（预发布）

> **预发布版本**，用于生产环境上线验收。验收通过后，将在**同一提交**上发布正式版 `v1.0.0`，已安装 rc.1 的服务器无需重新部署。不建议在验收之外的生产网站上使用预发布版本。

## 升级说明

- 这是第一个发布版本，**没有可升级的旧版本**；数据库结构版本为 7。
- 数据库迁移：首次安装时执行 `00001`–`00007`。
- 配置：首次安装时 `deploy/manage.sh install` 会在终端中引导填写，并自动生成数据库密码与 `APP_SECRET_KEY`。
- 需要人工完成的步骤：
  - 在 Nginx Proxy Manager 中新增代理主机；
  - 创建首个管理员；
  - 配置每日备份与异地备份。

## 安装

```bash
sudo git clone https://github.com/xiaowork-dev/xiaowork-blog.git /opt/xiaowork-blog
cd /opt/xiaowork-blog
sudo deploy/manage.sh precheck                         # 可选：只读环境预检
sudo deploy/manage.sh install v1.0.0-rc.1 --pre
```

需要：64 位 Linux、Docker Engine 24+、Compose 2.20+，以及已运行的 Nginx Proxy Manager（位于自定义 Docker 网络中）。完整步骤见 `docs/deploy/部署与运维手册.md`。

## 内容

V1.0 的全部功能：

- **博客前台**：首页、文章、分类、标签、归档、搜索、关于页；响应式与深色模式；代码高亮；RSS、sitemap、SEO；阅读量统计。
- **写作**：Markdown 编辑器，自动保存与实时预览；草稿与线上版本分离；撤回、回收站、旧链接 301 跳转。
- **用户与评论**：邮箱注册与验证、找回密码、会话管理；评论与回复发表即公开，作者可删除，管理员可治理。
- **管理后台**：控制台、文章、分类与标签、评论、用户、媒体库、网站设置、关于页、审计日志。
- **媒体与隐私**：按内容校验图片；未引用的图片不公开；上传时自动移除 EXIF / GPS / XMP。
- **安全**：`__Host-` 安全 Cookie、CSRF 防护、限流、可信代理、安全响应头（CSP、HSTS 等）。
- **部署与运维**：统一入口 `deploy/manage.sh`：
  - 安装、状态；
  - 从 GitHub Releases 检查与确认更新（只推荐正式版）；
  - 更新前自动备份，失败时自动回滚；
  - 回滚、备份、恢复、只读预检。

详细变化见 `CHANGELOG.md` 的 `[1.0.0-rc.1]`。

## 已知限制

- 依赖已有的 Nginx Proxy Manager；暂不提供独立反向代理安装模式。
- 单机部署，图片保存在本地目录；请配置异地备份。
- 回滚只切换应用版本，不回退数据库结构。
- 后台不能创建管理员或修改角色，管理员通过 `deploy/manage.sh admin create-admin` 创建。
- 剩余风险见 `docs/deploy/性能基线与剩余风险.md`。
