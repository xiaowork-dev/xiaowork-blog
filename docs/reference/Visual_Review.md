> 依据：此前 PRD、SAD、DD、API-DD、UI/UX 详细设计说明书。

## 一、已明确的视觉与功能边界

- **前台：** 现代简约、传统双栏，左侧只放博主头像、名称、简介、GitHub/邮箱等常用外链图标；右侧文章内容。左侧不需要分类、归档等导航小组件。
- **顶栏：** 放首页、分类、标签、归档、关于、搜索、主题和登录入口；视觉稿可以因空间只显示部分，但产品完整页面必须具备既定导航。
- **文章详情：** 右侧阅读内容为主体，目录不能挤占左侧个人资料栏；评论登录后直接公开，不设置人工审核。
- **编辑器：** Markdown 原文/分栏/预览，草稿自动保存不公开，只有手动发布/发布更新才上线；需处理 revision 冲突。
- **后台：** 功能型左侧导航；评论管理只能事后隐藏/删除/恢复；没有“待审核”标签或审核按钮。
- **账号：** 仅邮箱和密码注册与登录，邮箱验证、忘记密码。V1.0 不含 GitHub 第三方登录、记住我功能。
- **风格：** 低饱和中性色、蓝色少量点缀、充足留白、轻边框、可切换深色主题。

## 三、与正式需求不一致的图像细节（明确排除）

生成式概念图不是精确的产品验收图，可能含有额外控件或不准确文字；以下项**不属于最终 V1.0 设计**：

1. 图片中个人资料卡下方如果出现“首页 / 归档 / 关于”等第二组垂直导航，**全部删去**；左侧仅保留头像、名称、简介、外链图标；主导航全部移至顶栏。
2. 图片中可能出现的文章“收藏 / 书签”图标，**首版不实现**（PRD 未含收藏功能）。
3. 登录页可能出现的“记住我”、GitHub 登录或其他第三方登录，**首版不实现**；仅保留邮箱密码、忘记密码和注册入口。
4. 后台仪表盘中的示例数据、示意文章标题和时间均为**占位内容**，不是已生成的项目数据。
5. 图上缺失的文章标签、SEO 编辑、权限提示、媒体引用保护和评论等业务功能仍以 PRD/API/UI-UX 文档为准，**不能因为概念图未画出而取消**。
6. 个别文字、排版和图标细节可能存在生成误差，实施时不得当作精确设计令牌或接口命名。
