## 4. 许可证

**已采用 MIT License**（`LICENSE`，`Copyright (c) 2026 xiaowork-dev`），由项目负责人确认。

权利归属的核对：

- 截至本次审查的全部 29 个提交，作者都是 `xiaowork-dev <xiaowork-dev@users.noreply.github.com>`；
- 提交中的 `Co-Authored-By: Claude …` 表示由 AI 编程助手协助编写；
- 除 §3 中注明的 Tabler Icons 路径外，没有发现复制自第三方的源代码。

项目负责人按“前提是项目相关代码的权利归属允许如此标注”的要求，确认以 `xiaowork-dev` 作为版权标识。AI 辅助生成内容的权利以所用服务的条款为准，本审查不构成法律意见。

当时的选型理由：

- 依赖全部是宽松许可，没有冲突；
- 对自托管用户和二次开发者最简单；
- 与 Nuxt、Vue、Go 生态的主流做法一致。

其他可选方案：

- **Apache-2.0**：包含明确的专利授权与贡献条款，但文本更长；
- **AGPL-3.0**：要求修改后提供网络服务的人也公开源码。如果希望防止他人闭源托管，可以考虑；但这会降低采用率，也限制商业二次开发。
