## 2. 完成内容

### 2.1 Go API

| 接口 | 要点 |
|---|---|
| `GET /admin/overview` | 实时查询以下数据：<br>- 文章：总数、已发布、草稿、已撤回、回收站、有未发布修改；<br>- 用户：总数、未验证、已禁用、近 7 天新增；<br>- 评论：公开、已隐藏、近 7 天新增；<br>- 可用媒体数。<br>另返回最近 6 篇文章、最近 10 条审计记录，以及基于真实状态的提示（没删完的图片、只有一个管理员）。不做图表，没有任何审核数字 |
| `GET /admin/users`、`/admin/users/{id}` | 可按昵称或邮箱搜索，按状态、验证、角色筛选并分页。详情返回评论统计、有效会话数、最近 10 条评论，以及 `can_disable` / `can_enable` |
| `POST /admin/users/{id}/disable`、`/enable` | 只作用于普通用户；对管理员返回 409 `ADMIN_PROTECTED`，禁用自己返回 409 `CANNOT_DISABLE_SELF`。禁用时在同一事务内撤销全部会话和未使用的令牌，并写入审计日志；重复操作幂等 |
| `GET/PATCH /admin/site` | PATCH 只更新传入的字段，且只能是 API-DD §5.8 所列字段；传入其他字段（如 `smtp_password`）返回 400。文本会校验长度并拒绝不可见字符，联系邮箱会校验格式。Logo、Favicon、头像须为 READY 且非头像图片，校验时加 `FOR SHARE` 锁；写入审计日志 |
| `PUT /admin/site/social-links` | 整表替换，数组顺序即排序。图标只能是 github、mail、rss、link 之一；地址只能是 https 或单一 mailto 地址；最多 12 个。错误按 `links[i].field` 返回 |
| `PUT /admin/site/navigation-links` | 站内链接只能指向公开页面（不能是 `/admin`、`/account`、`/auth`、`/api`、`/media` 或以 `//` 开头）；外部链接只接受 https；最多 10 个 |
| `GET/PUT /admin/pages/about` | 保存即公开。标题 1–160 字，正文最多 1 MiB。正文里的图片按与文章相同的语法树规则提取，并检查 READY；`static_page_media` 随之同步，被引用的图片公开且受删除保护，移除后恢复为私有。纯文本同步写入；写入审计日志 |
| `GET /admin/media?usage_kind=` | 支持用逗号分隔多个用途。选择器默认列出 `ARTICLE,SITE,PAGE` 三类，不包括头像 |

## 5. 已知问题与风险

- **管理员只能在服务器上通过 `blog-admin create-admin` 创建**，后台没有角色提升功能（UI/UX 明确要求）。P8 的运维文档需要说明首个管理员的创建和备用管理员的建议。
