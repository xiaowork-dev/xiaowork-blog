## 2. 完成内容

### 2.1 文章 API（`apps/api/internal/article`）

**版本隔离**
- 三份数据各自独立：`articles` 保存元信息与状态，`article_drafts` 保存唯一的可编辑草稿，`article_publications` 保存每次发布的快照。
- 编辑只写草稿；公开接口只读当前发布快照。文章 ID 始终不变，所以将来的评论会一直挂在同一篇文章上。

**草稿保存** `PUT /admin/articles/{id}/draft`
- 请求必须提交完整快照，并带上 `expected_revision`。版本号不一致时返回 409 `DRAFT_REVISION_CONFLICT`，`details.current_revision` 给出服务器版本号。
- 缺少字段或含有未知字段返回 400。正文上限 2 MiB。

**发布** `POST /admin/articles/{id}/publish`
- 整个过程在一个事务里完成，依次是：
  1. 锁定文章，校验版本号；
  2. 确定 Slug，并写入 `article_slugs` 登记；
  3. 生成快照，内容包括纯文本、自动摘要、标签与媒体引用；
  4. 更新状态，写入审计日志。
- 重复发布同一版本是幂等的，返回 `published_changed=false`，不会产生新的发布记录。

**Slug**
- 字符集为 `^[a-z0-9]+(?:-[a-z0-9]+)*$`。
- 手动填写的 Slug 如果冲突，包括与历史 Slug 冲突，返回 409 `SLUG_TAKEN`，整个事务回滚。
- 自动生成的 Slug 冲突时追加后缀。
- 中文标题生成 `post-<id 前 8 位>`。
- 旧 Slug 保留，访问时 301 到新地址。

**媒体引用**
- 用 goldmark 解析 Markdown 语法树来提取引用，代码块里的地址不计入。
- 被引用的图片必须处于 READY 状态，否则返回 422 `MEDIA_NOT_READY`。
- 校验时对媒体行加 `FOR SHARE` 锁，与 P3 删除时加的 `FOR UPDATE` 互斥。
- 发布后图片随发布版本公开；某张图从新版本中移除后，会重新变为私有。

**撤回、回收站与恢复**
- 撤回 PUBLISHED→WITHDRAWN，公开地址与旧 Slug 都返回 404。
- 移入回收站后文章只读，返回 409 `ARTICLE_TRASHED`。
- 恢复后状态为 WITHDRAWN 或 DRAFT，**永远不会自动重新发布**。
- 这三个操作都是幂等的，并写入审计日志。

**分类与标签**
- 提供增删改查。Slug 冲突返回 409；删除仍被引用的分类或标签返回 409 `RESOURCE_IN_USE`。

**公开详情** `GET /api/v1/articles/{slug}`
- 返回内容包括分类、标签、封面、上一篇/下一篇、`canonical_path` 和 `resolved_from_old_slug`。
- 响应头为 `Cache-Control: public, no-cache`。

**其他**
- 新增 `db/queries/articles_admin.sql`（sqlc 生成代码），沿用 `store.ExecTx`。路由的 stage 改为 `P4`。

### 2.2 前端（Nuxt）

**Markdown 渲染**（`utils/markdown.ts`）
- markdown-it 设置 `html:false`，并配有链接和图片地址白名单。
- 代码高亮用 Shiki（JS 正则引擎、16 种语言、明暗双主题）。
- 支持任务列表；表格外包一层可横向滚动的容器。
- 编辑器预览与公开页共用同一个渲染器。

**编辑器**
- 文件：`components/MarkdownEditor.vue`（CodeMirror 6，在客户端动态加载）和 `composables/useDraftEditor.ts`。
- 提供源码、分栏、预览三种模式。
- 工具栏覆盖标题、加粗、斜体、删除线、行内代码、链接、图片、引用、列表、任务、表格和代码块。快捷键为 Ctrl+B/I/K/E/S。
- 支持导入和导出 .md 文件，可从 MediaPicker 插入图片。
- 粘贴或拖入的图片会先插入占位文本，上传完成后再替换。

**自动保存与冲突处理**
- 停顿 1.5 秒后自动保存，请求按队列串行发出。
- 状态栏依次显示：未保存 → 保存中 → 已保存 / 保存失败 / 版本冲突。
- 网络出错时内容保留并自动重试；本地 localStorage 备份可以恢复。
- 离开页面时，如果有未保存内容会提示（路由守卫与 `beforeunload`）。
- 遇到 409 时停止自动保存，并排显示服务器版本和本地内容。用户可以载入服务器版本（被替换的文本仍可复制），也可以显式确认用自己的内容覆盖。冲突期间不能发布。

**文章设置抽屉**
- 包括摘要、分类、标签（可新建）、封面（MediaPicker）、Slug（前端校验）、SEO 标题和描述、评论开关，以及移入回收站或恢复。
- 在窄屏上，顶部固定显示“完成”按钮。

**页面**
- `/admin/articles`
  - 状态标签：全部、草稿、有未发布修改、已发布、已撤回、回收站。
  - 支持搜索和分页。
  - 每篇文章可以编辑、查看、撤回、移入回收站或恢复。
- `/admin/articles/new`：先创建草稿再跳转到编辑页。
- `/admin/articles/{id}/edit`
  - 状态标识：草稿、已发布、有未发布修改、已撤回、回收站。
  - 发布确认框列出标题、Slug 和是否首次发布。
  - 发布后可以直接查看公开版本。
- `/admin/taxonomy`：分类与标签管理。
- `/posts/{slug}`：服务端渲染的最小公开页，旧 Slug 返回服务端 301，不存在时 404。
- 后台导航中新增“文章管理”和“分类与标签”。

**依赖**：codemirror 6.0.2 及 @codemirror/*、markdown-it 15.0.3、shiki 4.5.0、vitest 5.0.5，全部固定精确版本，lockfile 已更新。

### 4.5 过程中发现并修复的问题

- 列表中的 `has_unpublished_changes` 与详情页计算方式不一致，从未发布的草稿会被误判，已统一。
- 内部 helper `text` 与 goldmark 的 `text` 包重名，已改名为 `pgText`。
- 测试原先预期正文超出 1 字节返回 413，实际按设计返回 422 `TOO_LONG`（只有请求体超过上限才返回 413），已拆分成两个用例。
- e2e 脚本生成的 PNG 测试图片缺少扫描线过滤字节，服务端正确地拒绝了它（`DECODE_FAILED`），已修正生成器。
- 一个 XSS 断言把属性值里已被转义的文本误判为事件属性，改为先清空引号内的值再检查。
- 窄屏下设置抽屉遮挡发布按钮，见 §4.4 第 7 条。
