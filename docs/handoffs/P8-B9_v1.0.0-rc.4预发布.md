## 9. 下一阶段的具体建议

项目负责人在 VPS 上自行执行（建议先备份）：

```bash
cd /opt/xiaowork-blog
sudo deploy/manage.sh backup --label before-rc4
sudo deploy/manage.sh check --pre
sudo deploy/manage.sh update v1.0.0-rc.4 --pre
```

然后：

1. 浏览首页、文章详情、深浅主题和手机端。
2. 对首页摘要里有代码或链接的文章执行“编辑 → 发布更新”，或填写手动摘要。
3. 如有问题：

   ```bash
   sudo deploy/manage.sh rollback
   ```

   回到 rc.3（没有数据库迁移，可直接回滚）。
