## 2. 完成内容

### 2.1 本地存储与图片处理（`apps/api/internal/media`）

- 目录：`originals/<2位>/<uuid>.<ext>`、`thumbnails/…`、`temp/`，位于 `MEDIA_ROOT`（Compose 绑定宿主机 `./.data/media`）。存储键只由随机 UUID 生成；客户端文件名仅作显示名（去目录、控制字符，≤255 字节）。
- 上传：multipart 流式写入 temp（O_EXCL/0600、边写边限长、不进内存）→ 校验 → 缩略图 → 原子 `rename` 入正式目录并 fsync 目录 → 写数据库；数据库失败时删除已移入文件；遗留 temp 文件 1 小时后清理。
- 校验：扩展名（jpg/jpeg/png/webp/gif）必须与内容嗅探一致；`DecodeConfig` 先检查尺寸（单边 ≤16384、像素 ≤ 上限）再解码；GIF 先扫描块结构计帧（≤500 帧、帧×像素 ≤5000 万）；最后完整解码。拒绝 SVG/HTML/脚本/伪装文件/截断文件。
- 限制（可配置）：文章/站点/关于页 10 MiB、2000 万像素；头像 2 MiB、约 419 万像素；同时最多 2 张解码；Linux/macOS 上卷空间不足时拒绝上传。
- 缩略图：静态图长边 >480 px 时生成（JPEG→JPEG，PNG/WebP→PNG）；GIF 不生成，始终返回原动画。
- 一致性：每小时清理 temp、重试未完成的删除、记录“有记录无文件 / 有文件无记录”报告；`blog-admin media-check` 可手动执行（只报告不删除）。
- 启动时检查媒体目录可写，不可写则 API 直接失败并给出日志。

### 2.2 媒体 API（API-DD §4.4 / §5.7）

| 接口 | 权限 | 要点 |
|---|---|---|
| `POST /api/v1/admin/media` | A | `usage_kind` = ARTICLE（默认）/SITE/PAGE；201 返回 `id,url,thumbnail_url,mime_type,size_bytes,width,height,visibility:"PRIVATE_UNTIL_REFERENCED"…`；每管理员 120 次/小时 |
| `GET /api/v1/admin/media` | A | `page,page_size(≤100),q（文件名，转义通配符）,usage_kind`；含上传者与引用数；隐藏已删除项 |
| `DELETE /api/v1/admin/media/{id}` | A | 两阶段删除；有任何引用返回 409 `RESOURCE_IN_USE` 与各通道计数（不含私人内容）；无引用 204；并发新增引用时恢复 READY |
| `GET`/`HEAD /media/{id}/file[?variant=thumb]` | P/S/A | 被已发布文章/站点设置/关于页/正常用户头像引用 → 匿名可读（`public, max-age=300`）；否则仅管理员或头像本人（`private, no-store`）；其余统一 404；`nosniff`、`CSP sandbox`、ETag、Range |
| `POST /api/v1/me/avatar` | S | 只改本人资料，媒体与资料同一事务；旧头像无引用即删除；10 次/小时 |

`/api/v1/admin/*` 的统一管理员守卫保持不变；上传接口不受 15 秒 JSON 超时限制，改为每请求期限（上传/下载 2 分钟）。

## 5. 已知问题与风险

1. **原图保留 EXIF/GPS 等元数据**（为遵守 MEDIA-07 不改动原图）；头像或照片可能泄露拍摄位置。建议后续评审是否在上传时提示或剥离。
2. Linux 宿主机上 `.data/media` 必须属于 10001:10001，否则 API 启动失败（CI 已在启动前设置；部署文档在 P8 完善）。
3. 公开图片 `max-age=300`：文章撤回后最长 5 分钟内浏览器/中间缓存可能仍有副本（DD §7.5 已说明无法追回已被缓存的副本）。
4. 剩余空间检查只在 Linux/macOS 生效（本机 Windows 开发跳过）。
5. 动画 WebP 预计被拒绝（未专门测试）。
6. `MediaPicker` 尚未接入页面，将在 P4 编辑器中使用；用户中心的头像上传界面随用户中心阶段实现（本阶段提供 API）。
7. P2 遗留：`TRUSTED_PROXY_CIDRS` 本地默认值需在 P8 收紧；本机 `go test` 执行拦截与 Docker Desktop SMTP 端口映射问题仍存在（CI 不受影响）。
