## 6. 发现并修复的问题

1. **“我的收藏”页列表不显示**：
   - 原因：使用 `server:false` 加载时，服务端渲染了空状态，而客户端先渲染骨架屏，水合不一致导致 DOM 损坏；
   - 修复：把 `idle` 状态也视为加载中。修复后逐页水合检查全部干净。
2. **相关文章重复渲染**：侧栏和窄屏底部各渲染了一份，DOM 和 id 重复。改为只渲染一次，窄屏时侧栏移到正文之后。
3. **e2e 断言写死旧类名** `class="toc-side"`：改为匹配类名。修改过程中替换脚本把 `\b` 写成了不可见的退格字符，导致断言一直失败，已清除；断言现在会输出各子项结果，便于排查。
4. **迁移测试**写死“7 个版本 / 24 张表”，并占用 00008 作故障迁移：已更新为 8 / 25，故障迁移改用 00009。
5. 截图脚本在文章超过 50 篇时找不到测试文章（只影响测试）：改为 100 篇一页。
