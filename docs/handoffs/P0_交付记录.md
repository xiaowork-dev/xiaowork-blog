## 5. 风险与遗留问题

1. **仓库可见性为 Public**：用户要求私有仓库，但 2026-10-23 在 GitHub 仓库页实测显示 `Public`（未登录也可查看 Actions 运行）。已推送内容不含任何密钥（见 §7.2），但设计文档与代码目前公开可见。需用户在 GitHub Settings → Danger Zone 改为 Private（Agent 不修改仓库设置）。
2. **前端 lint 尚未接入**：IMP §4 P0 提到 CI 跑 Nuxt lint；当前只有 typecheck + build。建议在 P0 收尾或 P1 开头引入 `@nuxt/eslint`（需新增依赖，未擅自添加）。
3. **本机默认 Node 为 20**：PATH 中 `nodejs20` 优先于 `nodejs24`；直接开发前需切换，否则版本不符（Docker 构建不受影响）。
4. **镜像 digest 未固定**：目前按版本标签锁定（`postgres:18.6-alpine`、`golang:1.27.3-alpine`、`node:24.22.1-alpine`、`alpine:3.22`），按计划在 P8 改为 digest。
5. **数据库密码字符限制**：密码原样拼入 `DATABASE_URL`，含 `@ : / ?` 等字符会导致连接串解析错误，已在 `.env.example`/README 说明。
6. **Nuxt 依赖有新版本**（vue 3.5.44、vue-router 5.x、typescript 7.x 等）：保持当前锁定版本，升级另行评估。
7. 本地 `.env` 与 Docker 卷 `xiaowork-blog_blog_postgres` 保留在本机，当前三个容器仍在运行；停止请用 `docker compose down`（不要加 `-v`）。
