# ADR-0011 — P8-B8 轻量视觉升级与自动摘要

- 日期：2026-10-25
- 状态：已采纳（P8-B8，等待项目负责人验收）
- 依据：项目负责人的 P8-B8 要求（保留简洁 UI 与“顶栏 + 左资料栏 + 右文章列表”布局，参考 AiEDU 封面卡片与 InyBit 色彩层次，不做门户化）；UI/UX §0.1、§2、§4.1；ADR-0004

**没有数据库迁移（结构版本仍为 7），`deploy/.env` 没有新增配置。** 本阶段没有连接生产服务器。

| # | 决定 | 理由 |
|---|---|---|
| 1 | **只改样式与少量组件结构，不改布局和功能**。<br>- 顶栏、左资料栏、右文章列表保持原样；<br>- 文章列表仍是单列图文卡片（不改四列瀑布流）；<br>- 资料栏仍只有头像、昵称、简介、外链 | 用户明确喜欢现有的简洁布局 |
| 2 | **统一 Design Tokens**：在 `main.css` 中为浅色和深色分别定义背景、卡片、文字、边框、强调色、青 / 橙 / 紫三种低饱和点缀色、代码背景、阴影和 `--brand-gradient`。<br>所有文字组合实测 ≥ 4.5:1（UI/UX §2.2.1） | “颜色更丰富，但布局更克制”；对比度可验证 |
| 3 | **渐变只用于细线和资料卡浅色带**：卡片悬停时的 2 px 顶线、阅读进度条、标题竖条、分类圆点。<br>不做大面积高饱和渐变，没有持续发光或循环动画；悬停只改变边框、阴影和封面 1.03 倍缩放，并尊重 `prefers-reduced-motion` | 用户要求“不使用持续发光、频繁动画或复杂背景特效” |
| 4 | **封面卡片**：<br>- 封面固定 16:9，`object-fit: cover`，带 `width` / `height` 属性，避免布局跳动；<br>- 前两张卡片 `loading="eager"` + `fetchpriority="high"`，其余懒加载；<br>- 加载失败时显示浅色占位和图片图标，不显示破图；<br>- 挂载时检查 `complete && naturalWidth === 0`，覆盖 SSR 阶段错误事件已错过的情况；<br>- 无封面时仍是纯文字卡，不留空白占位 | 统一比例、首屏性能与降级效果 |
| 5 | **卡片信息层次**：分类胶囊（带渐变圆点）+ 日期 → 标题（20 px / 700）→ 摘要（有封面 2 行，无封面 3 行）→ 标签（按 slug 稳定映射到四种低饱和色调）+ 阅读数 | 标题、摘要、日期、分类、阅读量层次分明 |
| 6 | **自动摘要**：新增 `summaryText`，发布时自动摘要改用它生成。它跳过代码块、表格、图片、原始 HTML、自动链接，以及长 URL（连同紧贴的短标签，如“参考：”）。<br>搜索用的 `body_plain_text` 仍包含代码，不受影响。<br>手动摘要优先的逻辑（`coalesce(draft.summary, fallback)`）不变 | 修复“代码命令混入首页摘要”；SSR、SEO、RSS 都读同一个 `summary`，前后端一致；不需要迁移 |
| 7 | **不批量改写已发布文章的摘要**：已发布文章的自动摘要保存在 publication 中，更新到新版本后保持原样。<br>作者编辑该文章并“发布更新”后，会按新规则重新生成；也可以直接填写手动摘要。<br>没有内容变化的重复发布是幂等的，不会重新生成 | 用户要求不得修改已有文章或已发布内容 |
| 8 | **文章详情**：<br>- 分类胶囊和日期放在标题下方，摘要使用左侧强调线的浅色块；<br>- 封面作为 16:9 头图，正文已包含同一张图片时不再输出头图；<br>- 代码块使用站点 `--code-bg`（只采用 Shiki 的文字颜色），`tab-size: 4`；<br>- 引用、表格（表头底色、斑马纹、单词不在中间断行）、链接（下划线偏移）、图片（圆角细边框）重新排版，正文行高 1.85 | 中文长文阅读舒适，避免封面重复 |
| 9 | **编辑器**：<br>- 工具栏按标题 / 强调 / 块 / 代码 / 插入分组并加分隔线，悬停时显示强调色；<br>- 源码 / 分栏 / 预览改为分段按钮；<br>- CodeMirror 使用基于站点 Token 的 Markdown 语法高亮，以及更柔和的当前行和选区；<br>- 预览区正文最大宽度 760 px。<br>为此把 `@lezer/highlight@1.2.5` 声明为直接依赖：它原本就是 CodeMirror 的间接依赖，版本与锁文件一致。<br>保存、发布、冲突检测逻辑没有改动 | 改善可读性；深色模式下默认语法颜色对比度不足 |
| 10 | 后台其他页面只做共用配色协调：按钮悬停色、后台导航激活态加左侧色条 | 本阶段不重构后台 |

## 后果

- 已上线文章如果自动摘要里有代码或链接，需要作者编辑并发布更新，或者填写手动摘要，才会变干净（rc.4 发布说明中已写明）。
- 更新需要重新构建 web 镜像（依赖多了一个已存在于锁文件中的包）。服务器访问 npm 源不稳定时，可在 `deploy/.env` 中设置 `NPM_REGISTRY` 镜像。构建失败时更新会在切换版本前中止，网站继续运行旧版本（演练中实际遇到一次并已验证）。
