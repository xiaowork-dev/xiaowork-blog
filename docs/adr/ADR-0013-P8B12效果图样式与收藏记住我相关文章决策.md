# ADR-0013 — P8-B12 按效果图改版，并加入收藏、记住我、相关文章

- 日期：2026-11-01
- 状态：已采纳（P8-B12，等待项目负责人看截图验收）
- 依据：
  - 项目负责人提供效果图（8 个页面），指出“第一张是我想要的效果”；
  - 对话中逐项确认：
    - 配色改回效果图的蓝色；
    - 资料卡下加导航；
    - 新功能做“相关文章、收藏、记住我”，不做“阅读时长”；
    - 先看截图再发版。
- 取代：ADR-0012 的配色；ADR-0011 中卡片结构的部分（16:9 封面、四色标签）。

| # | 决定 | 理由 |
|---|---|---|
| 1 | **配色回到蓝色**：浅灰页面 + 白卡片 + `#2563EB`；深色为深海军蓝。<br>按钮单独使用 `--btn-bg` / `--btn-fg`，深色模式下也是白字蓝底，与效果图一致；对比度 5.17。<br>标签改为“分类蓝色胶囊 + 普通标签中性灰”，去掉 P8-B8 的四色标签与 `tagTone` | 效果图要求 |
| 2 | **紧凑卡片**：<br>- 左封面 220 px、16:10，手机端封面在上、16:9；<br>- 标题 17 px，摘要 2 行；<br>- 分类与标签一行；<br>- 日期 · 阅读量 + 书签按钮 | 效果图要求；没有“阅读时长”（负责人未选） |
| 3 | **资料卡下增加站点导航**（复用顶栏配置的内部链接，不新增配置）：桌面为竖排菜单，选中项有左侧色条；窄屏为横向标签 | 负责人确认，改变 UI/UX §0.1 #2 的原决定（已在文档中标注） |
| 4 | **文章详情改用独立布局** `layouts/post.vue`：<br>- 正文 + 右侧 272 px 侧栏（目录卡片 + 相关文章），不再显示左侧资料栏；<br>- 窄屏时侧栏移到正文与评论之后，目录改为正文顶部的折叠目录；<br>- 相关文章组件只渲染一次 | 效果图要求；避免重复 DOM 与重复 id |
| 5 | **相关文章** `GET /articles/{id}/related`：<br>- 最多 3 篇，得分 = 共享标签数 × 2 + 同分类 × 1，再按最新排序，不足时用最新文章补齐；<br>- 文章本身不公开时返回 404；<br>- 浏览器端加载，不阻塞正文 SSR | 简单、可解释、无需额外表 |
| 6 | **收藏**：<br>- 新表 `article_bookmarks`（迁移 00008，只新增），主键 `(user_id, article_id)`；<br>- 接口：`GET /me/bookmarks`、`GET /me/bookmarks/ids`、`PUT` / `DELETE /me/bookmarks/{id}`（都是幂等的）；<br>- 只能收藏公开文章，上限 1000 篇，每用户每分钟 60 次；<br>- 撤回的文章收藏保留但不显示；<br>- 个人中心新增“我的收藏”；<br>- 收藏状态只在浏览器端加载，SSR 页面不含个人数据；<br>- 游客点击时跳转登录并带回原页面 | 负责人确认，PRD 原本不做（已在 PRD 中标注变更） |
| 7 | **记住我**：登录接口新增可选 `remember_me`。<br>- 省略或 `true`：14 天持久 Cookie（与以前一致，旧客户端不受影响）；<br>- `false`：会话 Cookie（没有 Max-Age），服务器端最长 12 小时。<br>登录页默认勾选 | 负责人确认；兼容现有行为，不增加长期凭据 |
| 8 | **字体栈以具名中文无衬线字体开头**，不再以 `system-ui` 开头 | 负责人手机上整站显示为楷体/宋体风格（手机系统字体被 `system-ui` 选中） |
| 9 | 部署演练脚本的临时迁移编号由 8 / 9 改为 90 / 91 | 避免与真实迁移 00008 冲突 |

## 后果

- 数据库结构版本 7 → 8（只新增表）。更新会自动迁移；回滚到旧版本时旧代码不读这张表，可以直接回滚。
- 新增依赖：无。
- 首页卡片的书签按钮由浏览器端补充状态：刷新后会短暂显示未收藏，随后更新为实际状态。
