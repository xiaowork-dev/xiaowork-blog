# ADR-0005 — P5 博客前台、内容发现、SEO 与浏览量实现决策

- 日期：2026-10-23
- 状态：已采纳（P5）
- 依据：PRD §4、DISCOVER-01~06、POST-12；SAD §2；DD §5.9、§9.1、§11.1；API-DD §3.1、§4.1、§5.1、§7；UI/UX §2~§4、§8、§10；视觉评审稿 Draft 1

**未修改任何数据表（迁移仍为版本 7）**，也没有删除或改变已有接口。新增的接口均属于 API-DD §4.1 已列出的公开接口；下表列出它们的实现细节，以及新增的可选字段。

| # | 决定 | 依据 / 理由 |
|---|---|---|
| 1 | **公开列表** `GET /articles`：参数为 `page`、`page_size`（默认 10，最大 100）、`category`、`tag`、`sort=latest\|oldest`（参数非法时返回 422）。<br>每条摘要包含 API-DD §5.1 的全部字段，另加 `canonical_path`；标签批量查询，避免 N+1。<br>页码超出范围时返回空列表，但 `meta.total` 仍是真实总数 | API-DD §3.1、§5.1；DD §11.1 |
| 2 | `GET /categories/{slug}/articles` 与 `GET /tags/{slug}/articles` 在 `meta.category` / `meta.tag` 中带回名称和描述；Slug 不存在时返回 404。<br>`GET /categories` 与 `/tags` 只列出启用中的项，文章数只统计已公开的文章 | API-DD §4.1 |
| 3 | **搜索** `GET /search/articles`：<br>- 关键词按空白拆分，最多 5 个词，**每个词都必须出现**在标题、摘要或正文中，用 ILIKE 子串匹配，大小写不敏感，`%`、`_` 按字面处理；<br>- 排序：标题全部命中的排最前，其次是摘要命中，最后按发布时间倒序；<br>- 关键词为空或超过 100 字返回 422；每个 IP 每分钟 60 次，超出返回 429；<br>- `meta.q` / `meta.terms` 供前端安全地高亮关键词。<br>**这是关键词匹配，不是语义搜索**，界面上的文案也是这样说明的 | DISCOVER-01；API-DD §7；DD §9.1 |
| 4 | 中文不分词。子串匹配天然支持“容器”“数据库”等短词，`pg_trgm` 索引只用于第一个关键词（长度≥3）的预过滤。<br>DD-16 所列的样本（容器、容器化、数据库、Java、Go、Spring Boot、Vue 3、Docker Compose）已写入集成测试 | DD §9.1 “中文搜索必须专项验收” |
| 5 | **归档** `GET /archives?year=`：按年、月分组，`meta.years` 给出每年的篇数，最多返回 2000 篇（超出时 `meta.truncated=true`）。<br>**分组与日期显示统一使用站点时区 `Asia/Shanghai`**：Go 端用 `SiteTimeZone`，SQL 用 `AT TIME ZONE`，Nuxt 端用 `SITE_TIME_ZONE`。这样文章显示的日期和它所在的归档月份一致，SSR（容器时区为 UTC）与浏览器水合时的输出也完全相同 | DISCOVER-03“统一口径”；如需其他时区，后续可改为配置项 |
| 6 | **站点资料** `GET /site` 只返回公开字段：站名、描述、个人栏、启用的外链与导航、Logo、Favicon、公开联系邮箱、默认 SEO。<br>`GET /pages/about` 在尚未编写时返回 404，前台显示简洁的占位内容。两者的编辑功能属于 P7 | API-DD §4.1、§5.8 |
| 7 | **浏览量** `POST /articles/{id}/views`：<br>- 必须带 CSRF 令牌和 Origin（跨站脚本无法刷量）；<br>- 同一浏览器上下文（会话 Cookie 或匿名 CSRF Cookie）对同一篇文章 **30 分钟内只计一次**；<br>- 机器人、爬虫、无头浏览器和命令行客户端的 UA 不计数；<br>- 每个 IP 每 10 分钟最多 120 次，超出返回 429；<br>- 只有已公开的文章可以计数，否则返回 404。<br>去重复用 P2 的持久化限流表 `auth_rate_windows`：只存 HMAC 摘要并带过期时间，不保存 IP、UA 原文，也不建立永久访客档案。**没有引入 Redis** | API-DD §7“不以 IP 身份或指纹构建永久追踪库”；DD §5.9 |
| 8 | 前端在文章**累计可见 5 秒**后才上报浏览（`visibilitychange` 会暂停计时），SSR 永远不计数 | API-DD §7“仅在客户端有效阅读后上报” |
| 9 | **阅读模式渲染**（`createDocumentRenderer`）：<br>- 只有当正文使用了 `#` 时才把整体标题层级下移一级，使页面标题成为唯一的 `<h1>`；<br>- 标题生成中文友好且唯一的锚点 id，并输出 h2/h3 目录；<br>- 代码块附带语言标签和复制按钮（固定标记，语言名经过转义）。<br>编辑器预览仍使用原渲染器。安全模型与 ADR-0004 #10 相同（`html:false` + 地址白名单） | PRD 4.2；UI/UX §4.2、§10 |
| 10 | 图片放大使用原生 `<dialog>`（Esc 关闭，关闭后焦点回到原图片），不在链接内的正文图片可以用键盘打开。<br>代码复制优先用 Clipboard API，失败时回退到 `execCommand` | PRD 4.2 |
| 11 | **SEO**：<br>- 每个公开页面在 SSR 中输出 title、description、canonical（绝对地址）、`robots`、Open Graph 和 Twitter Card；<br>- 文章页额外输出 `article:*` 和 JSON-LD `BlogPosting`（`<` 已转义）；<br>- 站点源地址由新增的 `NUXT_PUBLIC_SITE_URL` 提供，compose 中取自 `PUBLIC_BASE_URL` | DISCOVER-04 |
| 12 | **HTTP 状态如实返回**：<br>- 页码格式错误或超出范围、未知分类/标签、空的归档年份、文章不存在、已撤回或已删除，都返回 **404**；<br>- 旧 Slug 由服务端返回 301；<br>- API 故障时显示错误状态和重试按钮，并返回 **503**，避免被搜索引擎收录。<br>404/错误页带 `noindex` | UI/UX §8；P5 通过条件“HTTP 状态正确” |
| 13 | `sitemap.xml`、`rss.xml`、`robots.txt` 由 Nitro 路由在每次请求时从公开 API 生成（`Cache-Control: public, no-cache`），因此发布、撤回、删除后下一次请求就会更新：<br>- sitemap 包含首页、分类/标签/归档、关于页（已编写时）、全部公开文章，以及有公开文章的分类和标签；<br>- RSS 包含最新 20 篇文章的摘要；<br>- robots.txt 禁止抓取 `/admin`、`/account`、`/auth`、`/api/` 和 `/search` | API-DD §2；DISCOVER-05/06 |
| 14 | 后台、账号和认证页面发送 `X-Robots-Tag: noindex, nofollow` 与 `private, no-store`。搜索结果页使用 `noindex, follow`，且结果在浏览器端请求，使限流作用在真实读者的 IP 上 | DISCOVER-05 |
| 15 | **主题**：浅色 / 深色 / 跟随系统，保存在 localStorage 的 `xwb:theme` 中。`<head>` 内联脚本在首次绘制前设置 `data-theme`，避免闪烁；CSS 同时支持 `data-theme` 和 `prefers-color-scheme`，Shiki 也会随之切换 | PRD 4.2；UI/UX §10 |
| 16 | **顶部导航**：管理员配置了 `site_navigation_links` 时使用配置（只接受站内路径或 https 外链），否则使用固定的“首页 / 分类 / 标签 / 归档 / 关于”。<br>小于 768 px 时改为抽屉菜单（焦点锁定在抽屉内、Esc 关闭）；抽屉通过 Teleport 挂到 `body` 下，避免被顶栏的 `backdrop-filter` 截断 | UI/UX §3.1 |
| 17 | **左侧个人栏**只放头像、昵称、简介和外链图标（只接受 https 或 mailto）；PC 端 sticky，小于 1024 px 时变为文章前方的横向卡片。<br>文章目录放在正文右侧（≥1280 px），较窄时折叠在正文顶部，不占用个人栏 | PRD 4.2；视觉评审 §三 第 1 条 |
| 18 | 评论区不显示任何内容（P6 实现），不出现虚假评论或占位评论 | P5 范围 |

## 后果

- 搜索质量取决于子串匹配。同义词、错别字和语义相近的词不会命中；这是 V1.0 的明确边界。
- 浏览量是近似值：换浏览器、清除 Cookie 或 30 分钟后再次访问会再计一次；同一出口 IP 后面的多个读者共享 120 次 / 10 分钟的上限。
- 上线前仍需正确配置 `TRUSTED_PROXY_CIDRS`，否则 IP 限流会把所有请求视为来自同一个反向代理地址（P2 遗留项）。
