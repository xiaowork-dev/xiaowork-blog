# ADR-0004 — P4 文章、发布与 Markdown 编辑器实现决策

- 日期：2026-10-23
- 状态：已采纳（P4）
- 依据：PRD POST-01~12、SAD §5、DD §5/§7.2/§9.1/T03/T04、API-DD §4.3/§5.1~5.4/§5.8、UI/UX §7.3/§7.4

**未修改任何数据表（迁移仍为版本 7），未删除或改变 API-DD 中的接口。** 新增的错误码与可选字段见下表并已向后兼容。

| # | 决定 | 依据 / 理由 |
|---|---|---|
| 1 | **Slug 规则**：仅小写 ASCII 字母、数字与单个连字符，文章 ≤160、分类/标签 ≤100（P1 将字符集留给 API 决定）。草稿可暂存与他人相同的候选值，发布时由 `article_slugs` 主键裁决：手动指定冲突 → 409 `SLUG_TAKEN`（含历史 Slug，永不复用）；候选为空时沿用当前公开 Slug，从未发布则按标题生成（中文标题生成 `post-<id 前 8 位>`），自动生成冲突时追加后缀 | PRD POST-09“自动生成且唯一，可手动调整”；DD §5.4 |
| 2 | 回收站中的文章只读：保存草稿或发布返回 409 **`ARTICLE_TRASHED`**（新增错误码）；恢复后才可编辑 | DD T04；避免误编辑已删除内容 |
| 3 | 撤回：PUBLISHED→WITHDRAWN；重复撤回返回 200 与当前状态；草稿撤回 409 `ARTICLE_NOT_PUBLISHED`。移入回收站与恢复同样幂等（重复返回当前状态）；恢复只到 WITHDRAWN/DRAFT | API-DD §5.4 |
| 4 | 草稿全量 DTO：缺任何字段 → 400 `INVALID_REQUEST` 且 `details.fields` 指出缺失项；未知字段 → 400；正文 ≤2 MiB（略超 → 422 `TOO_LONG`，请求体 >2 MiB+64 KiB → 413）；摘要 ≤500 字、标签 ≤20 个 | API-DD §5.2“缺失关键字段视为 400” |
| 5 | **媒体引用解析**：后端用 goldmark 解析 Markdown 语法树，只统计图片、链接与自动链接中的 `/media/{uuid}/file`（含站点域名的绝对地址）；代码块、行内代码与原始 HTML 中的地址不计入。保存/发布时被引用的图片必须为 READY 且不是头像，否则 422 `MEDIA_NOT_READY`；校验时对媒体行加 `FOR SHARE` 锁，与 P3 删除的 `FOR UPDATE` 互斥，消除“边引用边删除”竞态 | DD §7.2“不能依靠简单文本子串匹配”、DD T06 |
| 6 | 发布时用同一语法树生成 `body_plain_text`（去 Markdown 标记、保留代码文本，供 P5 搜索）与自动摘要（前 160 字） | DD §9.1；PRD“摘要可以自动生成” |
| 7 | `has_unpublished_changes` = 草稿修订号 ≠ 最近发布的修订号，从未发布的草稿为 true；列表与详情一致 | API-DD §5.2 |
| 8 | 公开详情 `GET /api/v1/articles/{slug}` 返回 API-DD §5.1 字段及 `previous_article/next_article`，`Cache-Control: public, no-cache`（可缓存但每次须再验证，发布即生效） | API-DD §5.1、SAD §2.2“不先强开整页缓存” |
| 9 | 发布、撤回、移入回收站、恢复写入 `admin_audit_logs`；重复发布（无变化）不写审计 | DD §8.5 |
| 10 | **Markdown 渲染安全**：markdown-it `html:false`（原始 HTML 一律转义）+ 链接/图片地址白名单（http/https/mailto/相对地址；去除控制字符与空白后判断协议）+ Shiki 高亮（JS 正则引擎、16 种语言、GitHub 明暗主题，未知语言回退为转义文本）；任务列表复选框为固定标记。不依赖事后过滤 | SAD §5.3、API-DD §5.1 |
| 11 | 编辑器：CodeMirror 6；停顿 1.5 秒自动保存完整快照、串行队列（不会以同一 `expected_revision` 并发保存）；每篇文章在浏览器 localStorage 保留本地备份，异常后可恢复；409 时停止自动保存，并排显示服务器版本与本地内容，提供“载入服务器版本（被替换内容仍可复制）”和“用我的内容覆盖（显式确认）”两种选择 | UI/UX §7.4 第 4、7、9 条 |
| 12 | 粘贴/拖入图片：先插入占位文本，上传成功替换为 `![文件名](/media/{id}/file)`，失败只移除占位并提示，不影响周围正文 | UI/UX §7.7 |
| 13 | 新增最小公开页 `/posts/[slug]`（SSR 渲染公开快照，旧 Slug 服务端 301）以满足“发布成功后可以查看公开版本”；目录、评论、SEO 标签与完整阅读样式属于 P5 | P4 范围；UI/UX §4.2 |
| 14 | 分类与标签管理合并在 `/admin/taxonomy` 一页（UI/UX §7.1 导航中分为两项，P7 可拆分） | P4 只实现发布业务必需页面 |

## 后果

- 中文标题文章若未填写 Slug，地址为 `post-xxxxxxxx`；需要可读地址时请在设置中填写英文 Slug。
- 渲染安全完全由渲染器配置保证，已有 37 项单元测试（含 20 个 XSS 向量）；以后若开放任何 HTML 必须重新评审。
- 本地备份存放在管理员浏览器中，清除浏览器数据会一并清除（服务器草稿不受影响）。
