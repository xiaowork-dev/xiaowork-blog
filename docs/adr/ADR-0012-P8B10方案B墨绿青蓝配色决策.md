# ADR-0012 — P8-B10 配色改为方案 B「墨绿青蓝」

- 日期：2026-11-01
- 状态：已采纳（P8-B10，等待项目负责人验收）
- 依据：
  - 项目负责人看过 rc.4 线上截图后要求“重新设计颜色，整体风格不变”；
  - 从三套概念图（A 石墨靛紫、B 墨绿青蓝、C 午夜珊瑚）中选择了方案 B；
  - 本 ADR 取代 ADR-0011 第 2、3 条中的具体色值，其余决定（卡片结构、封面、摘要、编辑器）不变。

**只改颜色**：

- 不改布局、组件结构、功能和 API；
- 没有数据库迁移，没有新增 `.env` 配置。

| # | 决定 | 理由 |
|---|---|---|
| 1 | **背景改为带绿调的中性深色**（深色 `#0C1312` / 卡片 `#131D1B`，浅色 `#F4F7F6` / 白），主色改为青绿（浅 `#0F766E` / 深 `#2DD4BF`） | rc.4 深色模式下背景、卡片、顶栏都是相近的深海军蓝，层次不清；蓝色 Logo 与封面在蓝底上发闷。换成墨绿底后，层次与图片都更清楚 |
| 2 | **琥珀作唯一的暖色点缀**：分类圆点、行内代码（正文与编辑器源码一致）、标签色调之一 | 打破单一冷色，同时保持克制 |
| 3 | 四种标签色调改为青绿（主色）/ 天蓝（`--teal` 变量的值）/ 琥珀 / 靛紫，全部为低饱和底色 | 与主色区分；沿用原有变量名，组件代码不用改 |
| 4 | **原来写死在样式里的蓝色渐变改为 Token**：`--profile-band`（资料卡色带，按深浅主题分别定义，修复深色下青转棕发浑）、`--title-bar`（标题竖条）、`--mark-bg`（搜索高亮） | 换配色只需改 `main.css` 一处 |
| 5 | 导航当前页在浅色胶囊之外，加 2 px 主色下划线 | 概念图中确认的激活态 |
| 6 | 所有文字组合实测 ≥ 4.5:1（UI/UX §2.2.1） | WCAG AA |

## 后果

- 线上更新到下一个版本（建议 rc.5）后立即生效，不需要人工处理。
- 方案 A / C 的概念图保留在对话记录中，没有进入仓库；方案 B 的概念图位于 `docs/handoffs/assets/P8-B10/concept-B.webp`。
