# XiaoWork Blog V1.0 — 性能基线与剩余风险（P8-A）

## 1. 性能基线

**测量环境**：

- 隔离演练环境（Docker-in-Docker，运行在开发机的 Docker Desktop 上），生产构建；
- 请求链路为 nginx（模拟 NPM，TLS）→ Nuxt SSR / Go API → PostgreSQL 18；
- 数据量：13 篇已发布文章、若干分类、标签和评论；
- 客户端在开发机本地，每个地址顺序请求 40 次（先预热 3 次）；
- 测量脚本见交付记录。

这是开发机上的相对基线，不代表正式 VPS 的绝对性能。P8-B 上线后应在正式环境复测一次。

| 地址 | 状态 | p50 (ms) | p95 (ms) | 响应体（解压后） |
|---|---|---|---|---|
| `/` 首页（SSR） | 200 | 18.8 | 25.9 | 31 KB |
| `/posts/{slug}` 文章页（SSR，含代码高亮） | 200 | 17.2 | 26.3 | 22 KB |
| `/archives` 归档 | 200 | 15.8 | 20.7 | 18 KB |

**首页首屏静态资源**：

- 32 个 JS / CSS 文件，传输 **96 KiB**（brotli）。
- P8-A 开启 Nitro `compressPublicAssets` 前，同一首页的 JS 未压缩传输为 241 KiB。
- `/_nuxt/*` 带 `Cache-Control: public, max-age=31536000, immutable`。

**运行时内存**（演练环境空闲时，`docker stats`）：

| 服务 | 内存 |
|---|---|
| api | 11 MB |
| web | 208 MB |
| db | 127 MB |

**构建与更新耗时**（演练环境，依赖已缓存）：

- 首次安装（包括构建镜像）：约 3–4 分钟；
- 只改代码的更新：约 50 秒，其中切换 api / web 的中断不超过 15 秒。

## 2. 剩余风险

| # | 风险 | 影响 | 当前处理 | 后续建议 |
|---|---|---|---|---|
| R1 | **可信代理范围**是整个 NPM 网络网段 | 同一网络中的其他容器可以伪造 `X-Forwarded-For`，从而绕过按 IP 的限流 | 外部伪造已确认被忽略；运维手册 §12 给出了固定 NPM IP、改用 `/32` 的收紧方法 | P8-B 时确认 NPM 网络中是否还有其他服务，必要时收紧 |
| R2 | NPM 拿不到真实客户端 IP（rootless Docker 或关闭 iptables 时） | 所有用户共用一个 IP 的限流额度 | 运维手册 §4 给出检查方法 | P8-B 上线后用手机网络验证 |
| R3 | 回滚**不回退数据库结构** | 新迁移若改变了已有字段的语义，旧代码可能出错 | 迁移遵循“只增不删”；每次更新前自动完整备份 | 以后的迁移继续保持向后兼容，破坏性变更需分两个版本完成 |
| R4 | 单机部署：数据库、图片和本机备份在同一台服务器 | 服务器或磁盘损坏时会丢失数据 | 运维手册 §10 提供异地备份方案 | P8-B 必须配置异地备份并完成一次异地恢复演练 |
| R5 | 备份包含密钥和个人数据 | 备份泄露等于整站泄露 | 备份目录权限 700、文件 600；手册要求异地目标加密 | 定期检查异地存储的访问权限 |
| R6 | CSP 允许 `'unsafe-inline'` 脚本 | 内联脚本注入不会被 CSP 拦截 | Markdown 关闭原始 HTML、链接协议白名单、评论按纯文本显示，并有 XSS 用例 | 以后可以改为基于 nonce 的 CSP |
| R7 | 正式 SMTP 尚未验证 | 验证与找回密码邮件可能进入垃圾箱或无法送达 | 演练中通过 Mailpit 完整验证了收信流程 | P8-B 配置 SPF / DKIM 并实际收信（上线检查清单 D4、D5） |
| R8 | 正式 VPS 环境未实测 | 不同的内核、存储或 Docker 版本可能带来差异 | 已在隔离 Linux（Alpine + Docker 29.8）中完整演练 | P8-B 按上线检查清单逐项执行 |
| R9 | P8-A 之前已存储的图片没有去除元数据 | 只影响开发环境中的测试图片 | 生产环境尚无数据 | 无 |
| R10 | `update.sh` 会构建镜像，构建期间 CPU 与内存占用较高 | 小内存 VPS 上构建可能变慢或失败 | 构建期间旧版本继续服务，失败时不切换 | 内存不足 2 GB 时增加 swap |
