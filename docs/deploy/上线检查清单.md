## 回退预案

- 安装失败：网站尚未对外，NPM 中不添加 Proxy Host 即可，排查后重新运行 `install.sh`。
- 上线后发现严重问题：在 NPM 中暂时停用该 Proxy Host（不影响其他站点），排查后再启用。数据保留在卷和 `DATA_DIR` 中。
- 版本更新出现问题：使用 `deploy/rollback.sh`；需要回退数据时按手册 §8 恢复更新前的备份。
