## 回退预案

- 安装失败：网站尚未对外，NPM / 1Panel 中不添加代理即可，排查后重新运行 `sudo deploy/manage.sh install`。
- 验收中发现需要修改代码：修复后发布 `v1.0.0-rc.3`，用 `sudo deploy/manage.sh update v1.0.0-rc.3 --pre` 更新，重新执行受影响的检查项。
- 上线后发现严重问题：在 NPM 中暂时停用该 Proxy Host，或在 1Panel 中停用该网站（不影响其他站点），排查后再启用。数据保留在卷和 `DATA_DIR` 中。
- 版本更新出现问题：使用 `sudo deploy/manage.sh rollback`；需要回退数据时按手册 §8 恢复更新前的备份。
